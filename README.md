# WorldQuant University Capstone

This repository hosts Jupyter notebooks, markdown files, and related documents for the WorldQuant University Capstone project.

## Repository structure

- `notebooks/` - Jupyter notebooks used for analysis, experiments, and project deliverables
- `documents/` - Supporting project documents and markdown-based notes

## Getting started

1. Add project notebooks to `notebooks/`.
2. Add supporting markdown files and other documents to `documents/`.
3. Keep large generated artifacts and notebook checkpoint files out of version control using the existing `.gitignore`.
